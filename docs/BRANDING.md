# LibreGram branding

This document describes the first LibreGram-owned launcher identity assets.

## App icon directions

The initial vector set is intentionally small:

- **Original** — dark graphite background, white emblem, blue accent.
- **Graphite** — graphite monochrome treatment.
- **Ocean** — deep teal background and cyan accent.

All three are redraws of the LibreGram symbol supplied for this project. They are not replacements for the upstream project's copyright notices or third-party design credits.

## Rules

- Use the supplied LibreGram symbol as the source of the app identity.
- Do not reuse exteraless, Blueprint, Ayu, or other upstream icon artwork as a LibreGram-owned design.
- Keep the upstream icon-picker implementation where practical, but expose only the curated LibreGram collection in the final app experience.
- A launcher icon is not considered integrated until the manifest aliases, icon picker, app shortcuts, widgets, and installation behavior have been checked.
- Keep icon assets scalable and provide adaptive-icon layers for Android versions that support them.
